# Сайт «Департамент лесного хозяйства Заречной области»

Учебный проект, выполненный в ходе производственной (эксплуатационной) практики.
Организация, регион и все сведения на сайте условные.

Сайт написан на PHP и MySQL без использования CMS и сторонних фреймворков.

## Возможности

- 8 разделов главного меню: Главная, О департаменте, Новости, Деятельность, Гражданам, Документы, Обращения, Контакты;
- две цветовые схемы: стандартная («Лес») и версия для слабовидящих по ГОСТ Р 52872-2012
  (размер шрифта, три цветовые схемы, отключение изображений, интервалы);
- карта сайта (`/sitemap`, а также `/sitemap.xml` для поисковых систем) и собственная страница 404;
- баннеры (слайдер и боковые), лента новостей с постраничной навигацией, поиск по сайту, контакты;
- интернет-приёмная: обращения граждан и переписка по ним (система обмена сообщениями);
- учётные записи с ролями «Администратор», «Сотрудник департамента», «Гражданин»;
  самостоятельная регистрация и создание учётной записи сотрудником;
- раздел управления: материалы, обращения, пользователи, баннеры.

## Требования

- PHP 8.0 и выше (расширения `pdo_mysql`, `mbstring`, `dom`, `fileinfo`);
- MySQL 5.7+ или MariaDB 10.3+;
- веб-сервер Apache с модулем `mod_rewrite` (входит в XAMPP).

## Установка на локальный сервер XAMPP

1. Установите XAMPP и запустите модули **Apache** и **MySQL** в панели управления XAMPP.
2. Скопируйте папку проекта в `C:\xampp\htdocs\lesdep`.
3. Откройте phpMyAdmin (`http://localhost/phpmyadmin`), создайте базу данных `forest`
   с кодировкой `utf8mb4_unicode_ci`.
4. На вкладке «Импорт» последовательно импортируйте файлы `sql/schema.sql` и `sql/seed.sql`.
5. Скопируйте `config.sample.php` в `config.php` и при необходимости укажите параметры
   подключения (по умолчанию в XAMPP: пользователь `root`, пароль пустой).
6. Откройте сайт: `http://localhost/lesdep/`.

## Структура проекта

```
index.php            единая точка входа и маршрутизация адресов
.htaccess            перенаправление запросов на index.php, защита служебных файлов
config.sample.php    пример файла настроек
inc/                 ядро: подключение к БД, авторизация и роли, вспомогательные функции
pages/               обработчики страниц (получают данные и вызывают шаблон)
pages/admin/         раздел управления сайтом
templates/           шаблоны страниц и общий макет
assets/css/          style.css – основной стиль, a11y.css – версия для слабовидящих
assets/js/main.js    слайдер, настройки версии для слабовидящих, мобильное меню
assets/img/          изображения, логотип, схема проезда
assets/fonts/        шрифты Golos Text и PT Sans (лицензия SIL OFL)
sql/                 схема базы данных и начальное наполнение
tools/dev-router.php запуск на встроенном сервере PHP: php -S localhost:8000 tools/dev-router.php
```

## Безопасность

- запросы к БД выполняются только через подготовленные выражения PDO;
- пароли хранятся в виде хеша (`password_hash`, алгоритм bcrypt);
- все формы защищены CSRF-токеном, вывод данных экранируется;
- HTML-текст материалов очищается от скриптов и опасных атрибутов при сохранении;
- ограничение числа попыток входа; права доступа проверяются на каждой странице раздела управления.
